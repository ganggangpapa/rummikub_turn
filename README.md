# 🧩 루미큐브 턴 매니저 (Rummikub Turn Manager)

루미큐브를 할 때 **턴 시간 · 손패 · 점수**를 휴대폰 하나로 관리하는 웹앱(PWA)입니다.
설치나 빌드 없이 링크만 공유하면 누구나 쓸 수 있고, 홈 화면에 추가하면 앱처럼(오프라인 포함) 동작합니다.

> 비공식 팬 메이드 도구입니다. Rummikub®는 Kodkod/Lemada의 상표이며 이 프로젝트와 관련이 없습니다.

## 기능

| 탭 | 내용 |
|---|---|
| 👥 **설정** | 플레이어 2~6명, 이름·색·순서 변경, 🎲 선 정하기(순서 섞기), 턴 시간(30/60/90/120초 또는 직접 입력), 경고 시간, 시간 초과 패널티 장수, 시작 손패, 소리/진동 |
| ⏳ **게임** | 모래가 흘러내리는 **모래시계 타이머**(탭하면 일시정지), 남은 시간 경고음·진동, `드로우 후 종료(+1)` / `N장 내려놓고 종료` 버튼, 되돌리기, 시간 초과 시 자동 패널티 |
| 🟨 **큐브 표시판** | 플레이어별 남은 손패를 타일(큐브) 모양으로 표시, 첫 등록(30점) 여부, 남은 풀 장수, ± 수동 보정 |
| 📜 **기록** | 턴마다 행동·소요 시간·손패 수 기록, 플레이어별 평균 턴 시간/초과 횟수 통계 |
| 🏆 **점수** | 라운드 종료 시 승자 선택 + 남은 타일 합(조커 30) 입력 → 공식 방식으로 자동 계산(패자 −합, 승자 +총합), 라운드 누적 점수판, 결과 복사 |

그 밖에: 손패 0장이 되면 자동으로 점수 입력으로 이동 · 새로고침해도 상태 유지(localStorage) · 화면 꺼짐 방지(Wake Lock) · 다크 모드 · 키보드 단축키(Space 일시정지, D 드로우, P 내려놓기).

## 배포하기 (GitHub Pages, 무료)

1. 이 저장소를 `main` 브랜치에 푸시합니다.
2. GitHub 저장소 → **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 선택합니다.
3. `.github/workflows/pages.yml` 이 자동 실행되고, 잠시 후
   `https://<github-아이디>.github.io/rummikub_turn/` 에서 열립니다.
4. 이 링크(또는 QR 코드)를 친구들에게 공유하세요. 휴대폰에서 **공유 → 홈 화면에 추가**하면 앱처럼 쓸 수 있습니다.

Netlify, Vercel, Cloudflare Pages 등 아무 정적 호스팅에 폴더를 그대로 올려도 됩니다.

## 로컬에서 실행

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다. (서비스 워커는 `file://` 에서는 동작하지 않으니 서버로 열어 주세요.)

## 구조

```
index.html            화면 구성 (4개 탭)
styles.css            스타일 (라이트/다크)
app.js                상태·타이머·기록·점수 로직 (의존성 없음)
sw.js                 오프라인 캐시 서비스 워커
manifest.webmanifest  PWA 설치 정보
icons/                앱 아이콘
```

수정 후 배포할 때는 `sw.js` 의 `CACHE` 버전을 올려 주면 사용자 기기에 새 버전이 확실히 반영됩니다.
